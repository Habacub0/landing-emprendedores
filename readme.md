# Landing Page para Emprendedores

Landing page profesional migrada a control de versiones, TypeScript y POO
como actividad de las sesiones 13–16.

## Requerimientos
Requerimientos funcionales:
- El formulario de contacto valida nombre, correo y mensaje.
- Los datos del formulario se guardan y se pueden leer en formato JSON.
- El menú de navegación resalta la sección activa.
- La sección de testimonios se genera dinámicamente desde una lista de datos.

Requerimientos no funcionales:
- La página debe ser amigable, intuitiva y funcional.
- El código debe estar tipado (TypeScript) y organizado con POO.


## Estructura del sitio
•	¿Qué secciones tiene? (héroe, beneficios, testimonios, formulario de contacto, etc.)
o	El sitio cuenta con la sección “hero” que contiene el titulo principal de la Landingpage. 
o	Cuenta con la sección “recursos” que contiene las tarjetas. 
o	Cuenta con las sección “indicador”, flecha que motiva al desplazamiento. 
o	Cuenta con las secciones: “comunidad, contacto”
o	Cuenta con un footer, llamado “site-footer”
•	¿Qué partes son dinámicas? (formularios, menús, carruseles, contadores, validaciones)
o	Menú de navegación, botón de llamado a la acción, tarjetas. 
•	¿En qué archivo(s) .js está la lógica actual?
o	De momento, solo existe un js, que indica cuándo esta abierto el menú de navegación. 


## Tecnologías
- HTML5 y CSS3
- TypeScript
- Programación Orientada a Objetos
- Git y GitHub

## Cómo ejecutar
1. npm install
2. npm run dev
3. Abrir la URL local que muestra la terminal
